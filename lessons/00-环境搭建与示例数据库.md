# 00 · 环境搭建与示例数据库

> 本课目标：装好工具、初始化贯穿全课程的 `shop` 电商示例库，并跑通第一条 SQL。

---

## 1. 为什么后端工程师必须学 SQL

Rust 后端的日常：**API 收到请求 → 查询/写入数据库 → 返回 JSON**。其中 90% 的业务逻辑最终落在 SQL 上：

- sqlx / Diesel / SeaORM 都只是 SQL 的"翻译层"，不懂 SQL 就无法调试、无法优化；
- 排查线上问题靠 `EXPLAIN`、慢查询日志，这些全是 SQL 层面的能力；
- 数据库（PostgreSQL/MySQL/SQLite）是后端性能瓶颈最常见的地方。

## 2. 双环境说明

本教程使用**两套数据库**，SQL 语法 95% 相同：

| | SQLite | PostgreSQL |
|---|---|---|
| 定位 | 单文件、零配置，**本教程默认练习环境** | 生产级，Rust 后端事实标准 |
| 安装 | 系统自带 / `apt install sqlite3` | `apt install postgresql` |
| 启动服务 | 不需要 | 需要 (`systemctl start postgresql`) |
| 类型系统 | 动态（TEXT/INTEGER/REAL/BLOB） | 丰富（`NUMERIC`/`TIMESTAMPTZ`/`JSONB`/数组…） |
| 教程覆盖 | 00-13 课练习 | 进阶特性（15 课 JSONB、全文搜索等）+ Rust 项目 |

> **建议**：练习用 SQLite 快速上手；学完 15 课后装一个 PostgreSQL 走一遍 PG 专属内容，为生产环境做准备。

## 3. 安装与验证

```bash
# SQLite（本教程要求 >= 3.35，支持 RETURNING）
sqlite3 --version

# PostgreSQL（可选）
psql --version

# Rust（阶段五要求 >= 1.75）
cargo --version
```

### 3.1 让 SQLite 更好用（推荐）

```bash
# 每次连接自动开启外键约束 + 显示列名
cat > ~/.sqliterc <<'EOF'
PRAGMA foreign_keys = ON;
.headers on
.mode column
EOF
```

> ⚠️ SQLite 默认**不强制外键**，必须每次连接执行 `PRAGMA foreign_keys = ON;`（PostgreSQL 无此问题）。上面配置一劳永逸。

## 4. 初始化示例数据库

shop 库是一个精简电商系统，6 张表贯穿全部 20 课：

```
categories（分类）──┐
                    ├──▶ products（商品）──┬──▶ order_items（订单明细）◀── orders（订单）──▶ users（用户）
reviews（评价）────┘                      │                                │
      └────────── user_id ────────────────┴────────────────────────────────┘
```

| 表 | 行数 | 说明 |
|---|---|---|
| `categories` | 6 | 键盘/显示器/鼠标/耳机/书籍/椅子 |
| `users` | 8 | 含 1 个 admin |
| `products` | 24 | 价格用整数分存储 |
| `orders` | 20 | 5 种状态：pending/paid/shipped/completed/cancelled |
| `order_items` | 28 | 订单明细，联合主键 |
| `reviews` | 21 | 1~5 星评分 |

```bash
cd learn-sql
./setup/init.sh          # 生成 shop.db（SQLite）
```

### PostgreSQL 版（可选）

```bash
# 前提：PostgreSQL 服务已启动，且你有创建数据库的权限
createdb shop
psql -d shop -f setup/schema.pg.sql
psql -d shop -f setup/seed.pg.sql
```

## 5. 跑通第一条 SQL

```bash
sqlite3 shop.db
```

```sql
-- 查看所有表
.tables

-- 查看表结构
.schema products

-- 第一条查询：最贵的 5 个商品
SELECT name, price_cents
FROM products
ORDER BY price_cents DESC
LIMIT 5;
```

预期输出：

```
name                 price_cents
-------------------  -----------
Herman Miller Aeron  1099900
Steelcase Leap V2     699900
Dell U2723QE          459900
BenQ PD2705U          399900
LG 27GP850            329900
```

输入 `.quit` 退出。**从下一课开始，请跟着每课的示例亲手执行。**

## 6. 数据被改坏了怎么办

每课的 UPDATE/DELETE/事务练习都可能改数据。随时重置：

```bash
./setup/init.sh    # 删掉重建 shop.db，10 秒恢复
```

## 7. 三种运行 SQL 的方式

```bash
# 方式一：交互式（推荐学习用）
sqlite3 shop.db

# 方式二：命令行直接执行
sqlite3 shop.db "SELECT COUNT(*) FROM orders;"

# 方式三：执行 .sql 文件（教程脚本、迁移都用它）
sqlite3 shop.db < my_query.sql
```

PostgreSQL 对应：`psql -d shop` / `psql -d shop -c "..."` / `psql -d shop -f file.sql`。

## 8. Rust 视角预告

阶段五你会用 sqlx 连接同一个 shop 库：

```rust
let pool = SqlitePoolOptions::new()
    .max_connections(5)
    .connect("sqlite://shop.db").await?;

let row: (i64,) = sqlx::query_as("SELECT COUNT(*) FROM orders")
    .fetch_one(&pool).await?;
```

你会发现：**教程里学的每一条 SQL，都能原样放进 Rust 代码**——这正是先学 SQL 再学库的意义。

## 练习

1. 初始化 shop 库，分别查出 6 张表的行数，与上表对照。
2. 用 `.schema orders` 查看 orders 表结构，找出它有哪 5 个约束（提示：CHECK / DEFAULT / 外键…）。
3. 查询 users 表中 role 为 `admin` 的用户（用 `WHERE role = 'admin'`）。

<details><summary>答案</summary>

```sql
-- 1.
SELECT COUNT(*) FROM categories;  -- 6
SELECT COUNT(*) FROM users;       -- 8
SELECT COUNT(*) FROM products;    -- 24
SELECT COUNT(*) FROM orders;      -- 20
SELECT COUNT(*) FROM order_items; -- 28
SELECT COUNT(*) FROM reviews;     -- 21

-- 2. .schema orders 可看到:
--    user_id 非空 + 外键、status CHECK(5种取值)、status/total_cents DEFAULT、id 主键
--    共: NOT NULL、REFERENCES、CHECK、DEFAULT、PRIMARY KEY 五类约束

-- 3.
SELECT * FROM users WHERE role = 'admin';   -- diana
```
</details>
